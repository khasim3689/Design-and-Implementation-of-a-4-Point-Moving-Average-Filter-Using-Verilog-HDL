Moving Average Filter – README

Project: Design and Implementation of a 4-Point Moving Average Filter Using Verilog HDL

This project implements a 4-point Moving Average Filter using Verilog HDL in Xilinx Vivado. The filter stores the previous three samples, adds them with the current input sample, and divides the sum by 4 to produce a smoother output.

Features
8-bit digital input and output
4-point moving average operation
Verilog HDL implementation
Testbench-based simulation
Waveform verification
Vivado synthesis and RTL schematic
Tools Used

Verilog HDL | Xilinx Vivado | RTL Simulation | FPGA Synthesis

Formula:

data_out = (data_in + sample0 + sample1 + sample2) / 4

Outcome: Successfully designed, simulated, and synthesized the moving average filter for digital signal smoothing.
